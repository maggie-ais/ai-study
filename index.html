8 年电商运营，正在转 AI 产品

我在淘宝和抖音做过 8 年运营，2022 年从 0 到 1 开了一家面包店，月流水 8 万、3 个人。

这两段经历让我反复看到同一件事：大量时间花在重复判断上——写 SOP、看评价、算补货。所以我在学 AI 产品，想把这三件事做成能用的工具。

  • 会写 HTML 和 CSS
  • 会用 GitHub 部署网站
  • 下一步：学 JavaScript

我的作品

门店 SOP 助手

问题：3 个人的小店，SOP 全在我脑子里，新人上手要 7 天。

做法：写 PRD 定边界，设计 Prompt，然后拿 30 条真实问答逐条测。

结果：新人不用再天天问我，答错时也能看出错在哪一步。

评价分析助手

问题：外卖和点评的评价没人系统看，只能凭印象改，改完也不知道有没有用。

做法：先定 5 类标签，AI 分类 30 条，再用表格统计 + 人工抽检。

结果：定位到「出餐慢」是差评主因，不是我原来以为的口味问题。

库存预警表

问题：补货靠感觉，热卖的断货，冷门的积压。

做法：用 Excel 算日均销量和安全库存，条件格式把低于 3 天的标红。

结果：打开表就知道今天该补哪几款。
